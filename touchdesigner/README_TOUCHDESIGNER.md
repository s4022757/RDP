# TouchDesigner Integration Guide
### Project: *Libraries Against Loneliness • Reflect & Connect*
**Site:** RMIT Swanston Library Level 6 Wellbeing Installation

---

## 1. System Overview

```
 ┌────────────────────────┐         ┌─────────────────────────┐         ┌──────────────────────────┐
 │   Interactive Kiosk    │         │    Supabase Database    │         │      TouchDesigner       │
 │      PWA on Tablet     │ ──────> │      (Table: reflections│ ──────> │   Constellation Visual   │
 │ (3 Scales + Text/Audio)│  HTTPS  │     Flat JSON format)   │  POLL   │  (Projection / Display)  │
 └────────────────────────┘         └─────────────────────────┘         └──────────────────────────┘
```

The kiosk interface collects 3 rating scales (1–10) and an open-ended reflection (text or 30s voice recording). Before saving to Supabase, it formats the data as a **flat JSON object** pre-computed with normalized visual parameters specifically designed for TouchDesigner.

---

## 2. Flat Record Data Structure

Every row in the `reflections` table is structured as a flat object ready for TouchDesigner:

| Field Name | Type | Range / Format | Description & Mapping |
| :--- | :--- | :--- | :--- |
| `id` | String | `lal_172...` | Unique identifier for the reflection star |
| `timestamp` | ISO String | UTC Timestamp | Creation time |
| `score_connectedness` | Integer | `1` to `10` | Environmental connectedness score |
| `score_social_energy` | Integer | `1` to `10` | Social battery score |
| `score_collective_empathy`| Integer | `1` to `10` | Collective empathy score |
| `response_type` | String | `'text'` / `'audio'` | Media type |
| `response_text` | String | Max 300 chars | Text reflection (if provided) |
| `response_audio_base64`| String | Base64 URL | WebM/Ogg audio payload (if provided) |
| `audio_duration_sec` | Float | `0.0` to `30.0` | Recorded duration in seconds |
| **`td_star_brightness`** | Float | **`0.150` to `1.000`** | **Star luminosity** (mapped from Collective Empathy) |
| **`td_pulse_rate_hz`** | Float | **`0.20` to `2.20` Hz** | **LFO pulse cadence** (mapped from Collective Empathy) |
| **`td_color_hue`** | Float | **`0.08` to `0.65`** | **Color Hue** (mapped from Social Energy: 1=Cool Indigo, 10=Warm Amber) |
| **`td_color_r`** | Float | **`0.000` to `1.000`** | Pre-calculated Red float for Constant MAT |
| **`td_color_g`** | Float | **`0.000` to `1.000`** | Pre-calculated Green float for Constant MAT |
| **`td_color_b`** | Float | **`0.000` to `1.000`** | Pre-calculated Blue float for Constant MAT |
| **`td_line_thickness`** | Float | **`0.80` to `6.50` px** | **Constellation line thickness** (from Connectedness) |
| **`td_connection_distance`**| Integer | **`70` to `290` px** | **Connection link proximity** (from Connectedness) |
| **`td_star_scale`** | Float | **`0.80` to `2.40`** | **Particle star scale** |

## 3. How to Connect in TouchDesigner

### Option A: Using the Python Script (Recommended)
1. In TouchDesigner, add a **Table DAT** and rename it `table_reflections`.
2. Add a **Text DAT** or **Execute DAT** and paste the code from [`touchdesigner_poll_script.py`](./touchdesigner_poll_script.py).
3. Replace `SUPABASE_URL` and `SUPABASE_ANON_KEY` with your project credentials.
4. Set the Execute DAT to run periodically (e.g., via a **Timer CHOP** pulsing every 1–2 seconds).
5. The `table_reflections` DAT will automatically populate with rows containing all the flat parameters above.

### Option B: Using a Web Client DAT
1. Place a **Web Client DAT** in your network.
2. In the **URL** parameter, enter:
   `https://<your-project>.supabase.co/rest/v1/reflections?select=*&order=timestamp.desc&limit=25`
3. In the **Headers DAT**, provide:
   ```
   apikey           <your-anon-key>
   Authorization    Bearer <your-anon-key>
   ```
4. Attach a **JSON DAT** to the Web Client output to parse the response into DAT tables or Python dictionaries.

## 4. Visual Parameter Binding Guide

- **Star Brightness / Luminosity (`td_star_brightness`)**:
  - Connect to a Constant MAT's `Emit` or `Alpha` multiplier, or a Particle SOP's life color alpha.
- **Star Color (`td_color_r`, `td_color_g`, `td_color_b`)**:
  - Connect directly to the RGB channels of a Constant MAT, Line MAT, or Point SOP color attribute (`Cd[0], Cd[1], Cd[2]`).
- **Constellation Line Thickness (`td_line_thickness`)**:
  - Connect to a Line MAT's `Width` or GLSL line shader attribute.
- **Connection Clustering Distance (`td_connection_distance`)**:
  - Use to threshold neighbor distance in a Script SOP / GLSL compute shader that builds constellation line topology.

## 5. Offline Testing / Kiosk Simulator

You can test the entire pipeline without internet:
1. Open the kiosk PWA in a browser.
2. Click the gear icon in the top right to open the **TouchDesigner Bridge Drawer**.
3. View the live flat JSON generated by your current slider positions.
4. Click **Copy Flat JSON** to paste directly into TouchDesigner for instant node prototyping!
